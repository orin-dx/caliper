The numbers match the Nov 9 record exactly, but the label "Completeness" misleads, and the page shouldn't present it as how complete Caliper is. I downloaded the Nov 9 weekly.json (artifact of run 42637254796, kept in ~/Projects/caliper-fixtures/weekly-2026-11-09/) and checked.

What the number measures: "agree over the universe". The universe is every own prop the checker finds on any exported function whose only parameter is a props type. That includes functions that aren't components. docs/measurement.md says to read it as a comparison between tools, "not as a share of real components".

Ant Design (44.9% vs 44.8%): a universe artifact, not incompleteness.
- The universe is 7,199 props. Both tools omit about 3,700 of them, almost all for the reason "component": neither tool reports that function as a component.
- For the 185 components Caliper does report, it found all 185 and misses 0 props. Its agreement over those is 94.2%, with 1 wrong.
- So "low completeness is a shared limitation" is accurate, but "44.9% complete" invites the reading that Caliper finds under half of antd's props, which is false.

React Spectrum (30.7% vs 42.5%): a real gap, 11.8 points.
- The universe is 5,582 props. Caliper lists 2,023 and RDT lists 2,747.
- The stratum breakdown of what's missing:

┌──────────────────────────────────────────────┬─────────┬───────┐
│ Where the checker declares the missing props │ Caliper │  RDT  │
├──────────────────────────────────────────────┼─────────┼───────┤

├──────────────────────────────────────────────┼─────────┼───────┤

├──────────────────────────────────────────────┼─────────┼───────┤
│ Another project file                         │ 2,089   │ 2,098 │

- Almost the whole difference is props declared in dependencies. 741 of 5,582 is 13%, which covers the 11.8 points.
