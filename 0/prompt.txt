2. Key Technical Concepts:
   - **Pipeline:** Rust core with OXC parsing, SourceData → GlobalSourceData → resolver → ExtractionOutput. Rayon parallel resolution. Parse cache is positional MessagePack; `CACHE_SCHEMA_VERSION` is currently 12 on the #73/#74 branches.
   - **Render evidence** (extractor/evidence.rs). A function counts as rendering if it has any of:
     - JSX, or an element factory call (`createElement`, `cloneElement`, `jsx`, `jsxs`, `jsxDEV`)
     - a top-level hook call (`use[A-Z]`)
     - a top-level return of `null`, `children`, or a call to a PascalCase function
     - an element return type: `Element`, `ReactElement`, `ReactNode`, `ReactPortal`, `JSX`, or `Promise<…>` of one

     Generators never count.
   - **Wrapper evidence** for the first argument of a generic wrapper call: a function that renders, a PascalCase reference (leading `_` or `$` trimmed), a wrapped component (`is_component_wrapper_call`), or a tag string. A tag string needs either an element type argument or a factory payload (`TagNeedsPayload`). `createContext` is declined.
   - **Rename calls are component wrappers only if** the callee is `memo`, `observer`, contains "forwardref" (case-insensitive; the callee is peeled first, so `(forwardRef as T)(X)` counts), is `with[A-Z]…`, contains "Component", or is a curried call. An exported base is never hidden by its alias.
   - **Structured type args:** `Vec<CollectedType>` on `ComponentMapping.props_type_args` and `ExtendsRef` type_args. The text parsers are deleted. `synthesize_utility_alias` handles Omit, Pick, Partial, Required, PropsWithChildren (as `P & {children?: React.ReactNode}`), Readonly and PropsWithRef.
   - **`CollectedTypeAlias::Pick` / `::Omit`** are now `{ base, keys: CollectedType, file_path }`. `resolve_key_set` handles:
     - literals and unions
     - `Never`
     - `KeyOf`, using a detached state
     - `AtFile`
     - `Exclude` and `Extract`
     - aliases, via `apply_generic_args`
     - unfilled in-scope type parameters, which contribute an empty set
     - anything else: `None` plus a warning
   - **`ResolveState::branch()` / `detached()` / `absorb()`.**
   - **Binding:** `Binding<'b,'a>{init, span, annotation}` lets the detection rules apply to both declarators and default exports. `detect_component` runs the rule chain.
   - **Watch revision model (in progress):** an immutable `Revision` published through `ArcSwapOption`, a writer `Mutex`, a shared `assemble()`, and a thread-local dependency recorder (resolver/deps.rs) that records the files each component's resolution read.
   - **Calibration metrics (score.py):**
     - recall(own) and recall(any): recall(any) counts every react-docgen-typescript (RDT) component with props, which fixes the old metric's blind spot.
     - props(own)
     - extras
     - timing (timing.py)
     - output equality and determinism (same_output.py)
