- **Enabling `github-release` makes 0.9.0 look unfinished.** `callisto release pending` lists it as missing its GitHub Release. Without `--from`, the command stops with E166 on an older release whose decision no longer decodes. I pinned `RELEASE_PENDING_FROM=2daef927` (the 0.9.0 release commit).
