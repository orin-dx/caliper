  ## 5. Architecture
  (a) Extractor chain additions after try_hoc_wrapped: typed arrow/fn-expr; fn-arg at any position; `WrapperCall` owned record; destructure-from-call bindings; keep skip span.
  (b) Promotion pass in pipeline/ with tiers: callee-signature; type-shape heuristic (low confidence, ambiguous when a real props type has a `props` field); nothing. Then resolver fixes RC1-RC4, RC7.

  (d) Escape hatches: `/** @component */`; optional declarative config list (needs parse_file options, schema field, cache-key impact). Plugins not viable (not registrable, no AST).
  (e) Guard table: syntax-only signals reject destructured bindings, SCREAMING_CASE, lowercase names, namespace-member callees, React builtins (createContext), Provider/Context-suffixed names. Callee return-type check needs the callee declaration (R). createContext<T>() vs createSafeContext<T>('msg') is not separable by syntax.
  (f) Semantic: ADR 0007 "backend may discover components", opt-in, structural stays default and fallback, trigger = every exported component, optional JSX.ElementType assignability filter. Re-verify against 7.1.0-beta: exports (no typescript/unstable in nightly), checker methods, tsc-client lifecycle, overloads, static sub-components, barrels. Cost: ~385 ms/55 files vs structural 50 ms for 21 libraries.
