**What it is**
- **Method A:** The checker's normalized type, reused from `oracle-checker.ts`.
- **Method B:** The type the prop's declaration writes. It is read from source text with the stable TypeScript parser and never from the checker's type printer. The checker is asked only where the declaration is. B abstains on indexed or `keyof` types, no annotation, no declaration, or declarations that differ.
- **How they combine:** Identical or spelled is agreement. B looser than A means A stands alone. B contradicting A is contested and goes to a review file for a person. Where A has no type, B stands alone.
- **Scoring a tool:** Each prop is correct, less precise, wrong, contested, missing or layer, and each verdict keeps which methods backed it.
- **Layers:** A prop named in a collapsed layer's member list is a `layer`, surfaced but with no type to judge.
- **Sampler:** It takes a `--list` JSON of `{corpus, file, component, prop}` plus a seeded control sample, 100 per corpus by default. The sample is stratified over listed, generic, mapped, intersection, function, union-of-literals, dependency, HTML attribute, extends and own. It runs in about 2 s per corpus.

**Ten differences that carry information**

1. **antd `ActionButton.close`:** structural `(...args: any[]) =&gt; void`, checker `(args: any[]) =&gt; void`. Structural is right; the checker loses the rest marker (documented as "not carried").
2. **antd `Circle.format`:** structural `(percent?: number, ...) =&gt; ReactNode`, checker `(percent: undefined | number, ...)`. Structural is right; optional becomes required-with-undefined, which changes how a call site reads.
3. **Mantine `Accordion.__size`:** structural `__size`, checker `___size`. Structural is right; TypeScript's internal escaping adds an underscore and the checker mode doesn't remove it. It hits `__size`, `__vars`, `__clearable` and `__bottomSection`, over 1,000 props.
4. **shadcn `Accordion.onAuxClick`** (about 950 shadcn components; also `onGotPointerCapture`, `onTouchCancel`): the checker lists them and structural doesn't. The checker is right. Structural for components that wrap a Radix primitive reaches only about 16 props on the one I checked, while the checker resolves the DOM attributes. This is the gap the earlier docs describe ("2.3× the props where structural is behind").
5. **Mantine `bdrs`:** structural `StyleProp&lt;MantineSpacing&gt;`, checker the full union. Both are right; the checker is more useful for Storybook's select controls and much bigger.
6. **Chakra `AbsoluteCenter.2xl`:** structural `Nested&lt;SystemStyleObject&gt;`, checker a huge intersection. Both are right; this is the 482,000-difference expansion, so the checker mode multiplies Chakra's output and time.
7. **shadcn `Command.filter`:** structural writes out `(value: string, search: string, keywords?: string[]) =&gt; number`, checker `CommandFilter`. Both are right; structural is more informative here.
8. **Spectrum `gridArea`:** structural expands the responsive object `{ base?: string; S?: string; ... }`, checker `ResponsiveProp&lt;string&gt;`. Both are right; it's a toss-up for controls.
9. **Spectrum `defaultExpandedKeys`:** structural `Iterable&lt;string | number&gt;`, checker `Iterable&lt;Key&gt;`. Both are right; the checker keeps the declared name.
10. **antd `Avatar.onClick`:** structural `(e?: React.MouseEvent&lt;HTMLElement&gt;) =&gt; void`, checker `(e: undefined | MouseEvent&lt;HTMLElement, MouseEvent&gt;) =&gt; void`. Structural is right, again because the optional marker is lost.
