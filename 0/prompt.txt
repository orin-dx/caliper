## What each branch does
- **`sort`:** a file's demands all share the same `from` path, so the derived `Ord` compared a long path first on every comparison. They are now sorted by (specifier, name).
- **`lean`:** two changes.
  - **Resolve once per scope:** a module-only import is resolved once per resolution scope (nearest ancestor with `package.json`, `tsconfig.json`, `jsconfig.json` or `node_modules`). On shadcn, 2748 module-only demands become about 1316 resolutions.
  - **Scan without keeping the parse:** the React-augmentation search no longer keeps a full parse of files it only passes through. The package entry is still parsed in full. A file that cannot declare into React is read for its re-exports only, or skipped if it has none. Any file mentioning `declare module "react"` or `namespace React` still gets a full parse.

## Decisions for you
- **`cache-react-augmentations` dropped.** `merged_interfaces` costs about 14 ms thread-summed per 60k calls on main, roughly 0.25 µs per call, so under 2 ms of wall time. My cached version cost more (33 ms thread-summed, from lock contention). The earlier 5.5 ms estimate came from disabling the lookup entirely, not from making it cheaper.
- **`lean` is a memory win, not a time win.** Time is within noise of `sort`. Keep it only if the memory saving and fewer resolutions are worth about 410 added lines. The scope key assumes directories with the same scope resolve a bare specifier alike. It could be wrong where a `tsconfig` `references` list picks a config by `include`.
- **No dependency parse cache.** I measured instead of prototyping. A warm run with the persisted dependency index is 158 ms against 164 ms for `--no-cache`, only about 4% faster. The acceptance target is `--no-cache`, so a parse cache cannot help it, and it would touch ADRs 0003, 0008 and 0011.
- **Remaining cost:** loading dependencies still costs about 70 ms and 175 MiB on shadcn (164 ms / 313 MiB with, 95 ms / 139 MiB without). Getting back to the baseline needs a bigger change than these two branches.
