# caliper-docgen-storybook

## 0.6.0

- - **The Storybook addon documents more by default:** it reads dependency types (`loadDependencies`, default `true`) and lists every inherited prop (`collapseInheritedProps`, default `'none'`), so library-typed props resolve and fewer components fall back to Storybook's own docgen. New options: `htmlAttributes` (`'curated'` | `'full'` | `'none'`), `loadDependencies`, `collapseInheritedProps`.
  - **Fallbacks are visible:** a component handed to Storybook's docgen is logged once as a warning with the diagnostics that caused it.
  - **Edits to a tsconfig, `package.json` or lockfile reach the addon** like a source edit, instead of being missed until restart.
  - **The Vite plugin logs extraction diagnostics** once each (`logLevel`, `onDiagnostic`) and takes `htmlAttributes`.
  - **Windows paths work in the Vite plugin:** `C:\` source directories and backslash file paths are recognised.
- - **Chakra with `--load-dependencies` resolves instead of giving up:** the share of its components with a warning drops from 92% to 3%. Three causes, all fixed:
    - A type declared inside `namespace X {}` that names a sibling (csstype's `DataType.Color = ColorBase | ...`) now finds it. Its members were lost before, in project sources as well as dependencies.
    - `T extends unknown ? Omit<T, K> : never`, the idiom that distributes over a union, takes its true branch, so a props base written that way is no longer opaque.
    - The nesting limit counts one type expression. An alias body starts again at 0, and the declarations a reference passes through are bounded by the names in progress, so a prop 15 levels down no longer runs out of depth inside four csstype aliases.
  - The parse cache schema is unchanged.
- - **The Storybook addon answers a story up to 3.5× faster on large projects:** it no longer sweeps every source file from JavaScript on each request. The native session checks the files, in parallel, once per story (Spectrum's 129 real stories: 2.2 s → 0.6 s, 15 ms → 4 ms per story).
  - **Session start no longer serializes every prop:** the new `initializeSessionIndex` returns only each component's file, name and the diagnostics. Chakra with dependencies skips a 25 MB JSON round trip.
  - **The native binding uses mimalloc:** session start is 15–30% faster, and Chakra with dependencies peaks 9% lower (small projects peak 20–30 MB higher).

## 0.5.0

- **Curated mode also gives a prop beside `ComponentProps<"div">` the element attribute's type:** recharts' `onTimeUpdate` next to a div's attributes is now `ReactEventHandler<HTMLDivElement>` intersected with recharts' handler in the default curated mode too, not only in Full mode. Curated mode reads React's declarations for this lookup only (ADR 0013), so nothing else in its output changes.
- - **A library's own declaration wins over a built-in shortcut:** with `--load-dependencies`, a component typed with `HTMLChakraProps<"div">` or Chakra's `ButtonProps` gets the library's real props (139 and 146 of react-docgen-typescript's, against 1 and 0 before), and Mantine's `StylesApiProps` its 8. Shortcuts remain only as fallbacks: when the package isn't loaded, or when its declaration needs a type checker (cva's `VariantProps`).
  - **Fewer library shortcuts:** `SxProps`, `SystemStyleObject`, `SystemCssProperties`, `OverridableStringUnion`, `ThemingProps` and `StylesApiProps` are no longer special-cased. Without their package loaded they stay named references with an `UNRESOLVABLE_IMPORT` warning, like any other uninstalled type; `sxProps` is no longer emitted as a type kind.
  - **Generic call props:** a component built by a generic factory takes its props from the factory's result type when that resolves, and an `export *` barrel reaches any exported value. A prop two members declare intersects, and `any` absorbs the intersection.
- - **`Exclude`, `Extract` and `NonNullable` evaluate over literal types:** `Exclude<"small" | "medium" | "large", "large"> | "default"` is the union `"small" | "medium" | "default"` (an enum in the RDT format, so a select control), as TypeScript evaluates it. They used to print as written.
  - **Template literals with number or boolean parts expand:** `` `h${1 | 2 | 3}` `` is `"h1" | "h2" | "h3"`, also inside an alias's arguments.
  - **A conditional decided by a member read evaluates:** `Payload["variant"] extends string ? … : string` takes its branch when the member's type is known, including when the payload declares no such member (Mantine's `variant` props now print their variants or `string` instead of the conditional's source).
  - **Member reads inside an alias's arguments evaluate,** through mapped types such as csstype's `Fallback<T>`: Chakra's style props print csstype's property types (`ConditionalValue<Property.Filter | … | AnyString>`) instead of `CssProperties["filter"]`.
- - **Props through conditional, indexed and mapped types:** a props type built as `T extends keyof Recipes ? Recipes[T]["__type"] : …` with a known `T`, or as a mapped type over a known type's keys (`{ [K in keyof Variant]?: … }`), now lists its props instead of a warning. Chakra's recipe props (`size`, `variant`, …) now appear: 332 of the 363 react-docgen-typescript reports on Chakra with dependencies loaded, none before.
  - **An alias argument that reads a member prints as what it reads:** `ConditionalValue<ButtonVariant["size"]>` prints `ConditionalValue<"sm" | "md" | "lg" | undefined>`, as TypeScript does.
- - **Components declared inside a function body are not documented:** a factory's returned component (`function createLeaf() { const Result = forwardRef(…); return Result; }`) or a local helper exists per call, and no module imports it by that name. Each is now an Info `SKIPPED_CANDIDATE` diagnostic instead of a component; React Spectrum's two `Result` entries and antd's local `PurePanel`, which shadowed the module-level one, are gone.
  - **Fewer skip diagnostics:** a PascalCase local that matches no component pattern (`const Comp = asChild ? Slot : "button"`) is no longer reported.
- - **A re-exported member of an imported component is documented with `--load-dependencies`:** `export const CheckboxHiddenInput = ArkCheckbox.HiddenInput` has the props of Ark's `HiddenInput` (Chakra: 11 components that react-docgen-typescript reports). Without the package loaded there is nothing to show, so it is left out. The parse cache schema moves to 21.
- - **Inherited React event handlers take their element:** with `--html-attributes full`, a component extending `React.SVGProps<SVGSVGElement>` or `ButtonHTMLAttributes<HTMLButtonElement>` listed `onClick` as `(event: MouseEvent<T>) => void`, with React's type parameter unbound. It is now `(event: MouseEvent<SVGSVGElement>) => void`, as TypeScript reads it.
- - **`Exclude`, `Extract` and `NonNullable` come from TypeScript's own definitions:** they were matched by name and evaluated only over literals. Now `type Exclude<T, U> = T extends U ? never : T` from the project's `lib.es5.d.ts` is evaluated the way TypeScript does, so a conditional alias over a bare type parameter distributes over the members of its argument, through aliases, `(typeof LIST)[number]` and `boolean`. A project's own `type Without<T, U> = T extends U ? never : T` works the same. `T & {}` removes `null` and `undefined`. Without TypeScript installed, these print as written, as before.
  - **A generic alias with a long expansion prints by name, as TypeScript and react-docgen-typescript do:** `Responsive<DimensionValue>` instead of its 80 literals three times over (React Spectrum: exact agreement with react-docgen-typescript's type text rises from 67.5% to 78.1%).
  - **A union drops `never` and a union of nothing is `never`.**
- - **`CSSProperties["key"]` reads csstype with `--load-dependencies`:** a prop typed `React.CSSProperties["pointerEvents"]` was always `string`, and `["zIndex"]` always `number`. With dependencies loaded, they now have csstype's types, as TypeScript does: `pointerEvents`, `objectFit` and `resize` are enums, `width` is `string | number` plus its keywords. Without dependencies, the previous answers stay.
  - **Indexed access reads the declaration first:** `Leaf["value"]` reads through `Leaf`'s ancestors in other files and binds their type arguments, and a member of a React type (`ButtonHTMLAttributes<HTMLButtonElement>["formAction"]`) reads React's declaration in curated mode. These used to print the access unevaluated or the unbound parameter.
  - **A literal-union alias inside a union contributes its members:** `Size | "xl"` is one union of literals, so the RDT format shows it as an enum, and a member it repeats is listed once. Printed text is unchanged; in `--json` the alias's members replace a nested `{"kind":"literalUnion"}`.
- - **Less memory with `--load-dependencies`:** a generic alias reference no longer resolves its arguments before expanding the alias (the expansion reads them again), and equal props built for different components are one allocation. Chakra's peak memory with dependencies loaded falls from 522 to 388 MiB. Output is unchanged.
- **String defaults keep their source quotes:** `({ size = 'md' })` gives the default `'md'`, not `"md"`, in every output format, as react-docgen-typescript and Storybook's React docgen print it. A double-quoted or template-literal default keeps its own quotes too.
- - **An omitted type argument takes its parameter's default:** `interface Props extends DOMAttributes` with `DOMAttributes<T = FocusableElement>` binds `T` to `FocusableElement`, as TypeScript does. Event handlers inherited from a library no longer print an unbound `MouseEvent<T>` (React Spectrum: 1,208 props), and `type Pair<A, B = A[]>` used as `Pair<string>` is `{ first: string; second: string[] }`.
  - **The parse cache schema moves to 20** (type parameter defaults are stored with each file's declarations), so existing caches are rebuilt once.
- - **A union lists each member once:** a union built from aliases that resolve to the same type prints that type once, as TypeScript does. React Spectrum's collection `children` printed `ReactNode | null | ReactNode | null | …` and now prints `ReactNode | null | (ReactNode | null)[] | …`; `T[] | readonly T[]` prints `T[]`.
  - **JSON unions are flat:** in `--json` output a union member that is an alias of a union now contributes that union's members in its place instead of a nested `{"kind":"union"}`. Printed type text is unchanged by this.
- **A wrapper-built component gets the props its factory's result type adds:** `const Button = factory<ButtonFactory>(…)` now also lists the props the type `factory` returns declares beyond the payload, such as Mantine's `component` and `renderRoot`, as react-docgen-typescript does. The factory may be reached through `export *` barrels, and editing it updates the components it builds in watch mode. On Mantine's core package, 360 missing props are now reported.

## 0.4.0

- - **New package `caliper-docgen-storybook`:** a Storybook 11 addon whose docgen provider answers argTypes from a caliper-docgen session. It resolves `meta.component` and `meta.subcomponents`, converts with `@storybook/react`'s own converter, applies saved edits before each answer, and hands a component it can't find, or one whose extraction reported a warning or error, to React's docgen. On a four-component example its first answer took 43 ms against React's 504 ms, and later answers 0.4 ms against 0.7–1.5 ms.
