Package metadata and license. The crates and npm packages now carry repository, homepage, documentation and keyword fields and a README, so crates.io, docs.rs and npmjs.com link back to the project. Starting with this release the license is FSL-1.1-MIT (each version becomes MIT two years after its release); 0.2.1 and earlier stay AGPL-3.0-or-later.
